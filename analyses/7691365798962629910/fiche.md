# Série foot Paris FC / PSG (fruits) — Partie 3 « Ici, t'es personne »

Source : vidéo envoyée par l'utilisateur. ~200 k vues (selon l'utilisateur). Analyse par les images et les sous-titres.

**Chiffres** : ~200 k vues · 72 s · ~14 plans · plan moyen ~5 s · ~3,2 mots/s · 1er mot à 0,3 s.

**Accroche** : 0 s sur le banc, Pomino : « Bienvenue sur le banc, le citron. Ici, t'es personne. » Riposte immédiate : « Le banc, c'est pour l'instant, mon gars. » Mécanique : insulte d'un coéquipier jaloux + riposte.

**Structure** : 7 s le coach le fait entrer (« joue simple, pas de cinéma ») ; 12 s dribble, but (« 1 partout, c'est qui le citron maintenant ? ») ; 20 s l'équipe adverse (rouge) le méprise ; 25 s 2e but, doublé ; 33 s dans la cité : « ton doublé tourne partout, t'es la star de la cité » ; 41 s la mère : « même à l'hôpital on m'en parle » ; 49 s SECRET : il se strappe le genou en cachette : « personne doit savoir » ; 52 s Pomino a tout vu : « ton genou peut-être » ; 58 s le coach : « samedi derby, on reçoit le PSG, tu commences » ; 64 s TRAHISON : Pomino appelle Pastèquito (le rival de la partie 1, maintenant au PSG) : « j'ai un truc à te dire sur son genou ». Carton « Commente Partie 4 ».

**Pourquoi on reste** : 2 buts = plaisir ; ironie dramatique (nous savons pour le genou, pas le coach) ; le traître rebranche le méchant de la partie 1 → derby promis.

**Visuel** : vrais maillots Paris FC (écusson, sponsors réels), stade, cité au coucher du soleil, cuisine de la mère, vestiaire, voiture la nuit. 6 décors.

**Interaction** : on veut prévenir le héros ; carton « Commente Partie 4 ».

**À reprendre pour nous** : le succès qui « tourne partout dans la cité » (vidéo virale dans l'histoire) ; le coéquipier jaloux qui vend le secret au méchant ; finir sur un coup de fil entre deux méchants.
