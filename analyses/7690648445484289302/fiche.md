# Série foot Paris FC / PSG (fruits) — Partie 1 « Le foot, c'est fini »

Source : vidéo envoyée par l'utilisateur (snaptik). Environ 200 000 vues par partie selon l'utilisateur (chiffres exacts non récupérés).
Analyse faite à partir des images (sous-titres incrustés), sans transcription audio.

**Chiffres** : ~200 k vues · 53,5 s · ~12 plans (fondus enchaînés) · plan moyen ~4,5 s · ~3,4 mots/s · 1er mot à 0 s · sous-titres de 2-3 mots, blancs avec 1 mot jaune.

**Accroche** : 0 s : la mère jette les crampons du fils à la poubelle : « Le foot, c'est fini. Le foot, ça paie pas le loyer. » Factures « RELANCE » sur la table. Mécanique : quelqu'un qui l'aime détruit le rêve du héros, pour une raison qu'on comprend (l'argent).

**Structure** : 3 s il supplie (« dimanche c'est mon dernier match ») ; 5 s ultimatum (« lundi tu commences à la supérette ») ; 8 s le pote : « un recruteur du PSG dans les tribunes, joue ta vie » ; 13 s le rival pastèque le chambre (« le cactus ») ; 20 s faute violente + « rentre chez ta daronne » ; 25 s la recruteuse s'en va ; 28 s il se relève, dribble, but ; 36 s « on m'a jamais rien donné, alors je vais tout prendre » ; 41 s RETOURNEMENT : le PSG choisit le rival (« le talent, ça suffit pas ») ; 46 s appel d'un numéro inconnu : le Paris FC. Fin : « Ouais, je serai là » + carton « Commente Partie 2 ! ».

**Pourquoi on reste** : enjeu social immédiat (loyer, supérette) ; deadline (dimanche, un seul match) ; injustice finale (il marque mais c'est le méchant qui est pris) puis espoir en 3 s.

**Visuel** : 3D type Pixar, humains à peau de fruit (cactus jaune à piquants, pastèque musclée, myrtille bleue), cité HLM, terrain synthétique de quartier, drapeau français, maillots génériques. Gros plans visage aux moments clés.

**Interaction** : « Commente Partie 2 ! » en carton final ; débat sur l'injustice du recruteur.

**À reprendre pour nous** : ouvrir sur le parent qui casse le rêve pour une raison d'argent (enjeu social lisible) ; donner une petite victoire DANS l'épisode (le but) puis la reprendre (le méchant est choisi) ; finir sur une porte qui s'ouvre (appel inattendu) plutôt que sur une défaite sèche.
